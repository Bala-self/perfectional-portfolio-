BillPro — GST Billing System

01 A GST billing and business management system: invoicing, inventory, purchases, and reports, built as a REST API with a React frontend. Full-Stack · MERN

Problem

Businesses need a GST-compliant billing system — CGST, SGST, and IGST calculation with inventory and reporting — in one place.

What I built

  • Designed and built the backend REST API — invoices, products, purchases, quotations, customers, employees, and reports — with JWT authentication, bcrypt password hashing, Helmet, and rate limiting.
  • Implemented backend-validated inventory: stock-movement tracking, customer balance updates, and PDF invoice and quotation generation with PDFKit.
  • Wrote automated API tests with Jest and Supertest, and used MongoDB indexing, pagination, and aggregation for reporting.
  • Built the React frontend — dashboard, billing, inventory, and reports screens — on top of the API.

Stack

Node.js · Express.js · MongoDB · Mongoose · JWT · bcrypt · Helmet · Jest · Supertest · PDFKit

KADAI — E-Commerce Website

04 A responsive e-commerce web application featuring product browsing, search, shopping cart, wishlist, customer authentication, Cash on Delivery checkout, order management, and an admin dashboard. Built using Vanilla JavaScript and Firebase. Full-Stack · Firebase

Problem

An e-commerce business needs a complete online shopping experience where customers can discover products, manage their carts, place Cash on Delivery orders, and track purchases, while administrators manage products and orders.

What I built

  • Structured the application using HTML5, CSS, Tailwind CSS, and modular Vanilla JavaScript, separating shared components, page logic, and data services.
  • Integrated Firebase Authentication for customer accounts and Cloud Firestore for application data and e-commerce operations.
  • Developed shopping features covering product listings, product details, search, cart management, wishlist, and checkout.
  • Implemented Cash on Delivery order placement, customer order history, and individual order details without online payment integration.
  • Built an administration dashboard for product and order management, with additional coupon and review-management functionality.
  • Organized Firebase security rules and configuration files for database and storage access control.
  • Prepared local development instructions, Firebase setup documentation, and project testing documentation.

Stack

HTML5 · CSS3 · Tailwind CSS · JavaScript (ES Modules) · Firebase Authentication · Cloud Firestore · Firebase Storage

Key featuresProduct Catalogue · Search · Shopping Cart · Wishlist · Authentication · COD Checkout · Order Management · Admin Dashboard
